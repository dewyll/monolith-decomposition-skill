# Security policy

## Supported versions

Only the latest release on `main` receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private reporting instead: go to the **Security** tab of this
repository and choose **Report a vulnerability**. You will get an answer
within a few days, and credit in the release notes if you want it.

Things worth reporting include scripts that could execute or leak content
from the analysed codebase in unexpected ways, or instructions in the skill
that could lead an agent to take unsafe actions in a user's repository.
